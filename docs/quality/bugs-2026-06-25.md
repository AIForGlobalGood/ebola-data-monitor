| **CTQ** | Deploy parity |
| **Status** | Operator (code guard added) |

## [D2] Cron ingest publicly callable without CRON_SECRET

| Field | Value |
|-------|-------|
| **Severity** | 🟠 Major |
| **CTQ** | Source failure / security |
| **Status** | Fixed (code); Operator (env) |

### Summary
`GET /api/cron/ingest` returns 200 and runs full ingest (~57s) without Authorization header when `CRON_SECRET` is unset.

### Steps to reproduce
1. `curl -s https://ebola-crisis.vercel.app/api/cron/ingest`
2. Observe HTTP 200 and `reprocessed` in JSON

### Expected
401 Unauthorized without valid Bearer token on production.

### Actual
HTTP 200; ingest runs.

### Root cause
Auth only enforced when secret is non-empty; Vercel has no env vars.

### Fix approach
- [x] Require `CRON_SECRET` on Vercel (`settings.is_vercel`) — returns 503 until set
- [ ] Operator: `npx vercel env add CRON_SECRET production`
- [x] Document in `.env.example`

### Verification
Without secret on Vercel: `curl -s -o /dev/null -w '%{http_code}' $PROD/api/cron/ingest` → **503** until secret set, then **401** without Bearer
